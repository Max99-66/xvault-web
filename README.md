# 隐匣 · Web

白色、精简的 X 视频与图片收藏工具。复制公开帖子链接即可解析、分类、在线播放，或下载到当前浏览器供离线观看。无需安装 IPA、Apple 开发者账号或服务器。

## 使用

粘贴 X 帖子链接，点击「解析」，将媒体加入媒体库，再点「下载」。下载文件保存在本设备浏览器的 IndexedDB，不会自动写入相册，也不会上传到 GitHub。通过「整理」设置分类、标题和标签。

iPhone 推荐在 Safari 中「分享 → 添加到主屏幕」，然后从主屏幕打开并使用。首次在线打开后，网页界面可缓存离线使用；已下载的媒体可离线播放。下载时请保持网页在前台。Safari 与独立主屏幕应用可能使用不同存储环境，请选定一种方式后持续使用。

浏览器存储可能因手动清理或空间回收而丢失，不应作为唯一备份。打开已下载媒体后，可用「导出到文件」保留副本。浏览器内收藏不提供身份验证或跨设备同步。

## 发布至 GitHub Pages

本项目无构建依赖。将项目上传公开仓库后，在 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。工作流 `.github/workflows/pages.yml` 会运行测试并发布 `site/`。如果工作流早于 Pages 设置而失败，在 Actions 中重新运行即可。

也可将 `site/` 文件部署到任意静态 HTTPS 托管。所有静态路径均相对，支持 GitHub Pages 仓库子目录。

## 本地预览

需要 Node.js 22 或更新版本。运行 `npm test` 检查解析与媒体筛选，运行 `npm start`，打开 http://127.0.0.1:8766 。

## 解析服务

网页向公开第三方 FxTwitter API (`https://api.fxtwitter.com/status/{id}`) 发送帖子 ID，再从 `*.twimg.com` 下载原尺寸图片或最高可用分辨率 MP4。下载得到的是平台提供的媒体，不保证是上传前的未压缩原文件。无需提供 X 登录凭据。私密帖子、登录受限内容和直播不支持；第三方接口与跨域策略的变化可能影响解析和下载。

代码仓库只存储程序，不存储使用者输入的链接、分类或媒体。网页上线公开可访问，但收藏保存在各自设备的浏览器内。
